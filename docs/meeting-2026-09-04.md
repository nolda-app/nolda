## 핵심 방향 전환: 조건 선택 → 사용자 데이터 자동 분석

기존 방식(예산/시간/위치/취향을 사용자가 매번 클릭해서 입력)이 번거롭고 기존 서비스와 차별점이 없다는 피드백.

- **기존 서비스 패턴**: 조건 클릭 → 조건 클릭 → 조건 클릭 → 추천
- **NOLDA 지향점**: 사용자 데이터 분석 → 취향·소비패턴 파악 → 자동 추천

발표 시 이 차이를 초반부터 임팩트 있게 보여주는 것이 핵심 전략.

## 검토 중 아이디어 (개인정보 동의 필요, MVP 구현 여부 미확정)

- **카드 사용내역 기반 추천** — 최근 소비 카테고리(예: 카페)로 선호 추론, 예산과 함께 고려. 테스트용으로 토스 연동 검토.
- **사진 데이터 활용** — 최근 사진 AI 분석으로 성향/활동 패턴 추출, GPS로 방문 장소 파악.
- **통화 내역 데이터** — 대화 상대 분석 기반 동행자 추천("OO님과 함께 가는 것을 추천합니다").
- **장소 데이터 자동 수집** — AI 에이전트가 네이버 업체 정보를 수집·분석해 DB 자동 축적.
- **vLLM 활용** — Claude API 대비 자체 호스팅 LLM 검토.

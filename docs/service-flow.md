# 서비스 흐름 — 기능 시나리오

NOLDA를 처음 켜는 순간부터 코스를 다 돌 때까지, 사용자가 무엇을 보고 무엇을 하는지 순서대로 적었습니다. 화면 뒤에서 무슨 일이 일어나는지도 함께 표시했습니다.

구현 세부 사항은 [구현 지침서](feature-guide-taste-and-navigation.md)를 보세요.

---

## 한눈에 보기

```
① 로그인 ──→ ② 기록 연결 ──→ ③ 분석 ──→ ④ 취향 확인·수정
                                                  │
                                                  ▼
                            ⑥ 코스 시작 ←── ⑤ AI 코스 추천
                                 │
                                 ▼
                            ⑦ 길안내 → 도착 → 다음 장소 → 완주
```

한 줄로 말하면 이렇습니다.

> **질문에 답하지 않아도, 내 기록이 알아서 취향을 말해주고, 그 취향에 맞는 코스를 실제로 걸을 수 있게 안내한다.**

---

## ① 로그인

**카카오 또는 구글로 로그인**하거나 이메일로 가입, 또는 **로그인 없이 둘러보기**로 건너뛸 수 있습니다.

처음 온 사람이 가입부터 요구받으면 이탈합니다. 무엇을 해주는 서비스인지 보고 나서 결정할 수 있게 열어 뒀습니다.

소셜 로그인은 이메일만 필수로 받습니다 (카카오는 닉네임 동의항목을 켜지 않아 요청하지 않음). 로그인에 실패하거나 취소하면 원인을 안내하는 화면이 뜨고, **"홈으로 돌아가기"**로 다시 로그인 화면으로 돌아올 수 있습니다.

---

## ② 기록 연결 — 키오스크에서 고르고 카드 꽂기

햇살 드는 방 안의 키오스크 앞에 원숭이가 앉아 있는 장면으로 시작합니다. 설명 글 대신 **장면으로 "내 기록을 기계에 넣어 분석한다"**를 보여줍니다.

### 진행 순서

1. 키오스크 화면 **"분석할 데이터를 선택해주세요"**에서 **유튜브 / 사진첩** 타일을 누릅니다.
   - 고른 타일은 분홍 테두리와 ✓ 표시가 생깁니다.
   - 사진첩 타일을 누르면 사진 선택 창이 열리고, 고른 뒤 타일에 `N장`이 표시됩니다. 다시 누르면 선택이 해제됩니다.
2. 하나라도 고르면 화면 아래 안내가 **"카드를 꽂아주세요"**로 바뀌고, 책상 위 카드가 살짝 들썩입니다. 카드 위에는 **"카드를 클릭해주세요"**가 은은하게 떠 있습니다.
3. **카드를 누르면** 카메라가 카드 리더기로 다가가고, 원숭이 손이 카드를 슬롯에 꽂으며 노란 불이 깜빡입니다 (1.5초).
4. 장면이 끝나면 실제 연결이 시작됩니다.
   - 유튜브를 골랐으면 → 구글 로그인 화면으로 이동
   - 사진첩만 골랐으면 → 바로 ③ 분석

| 이럴 때 | 어떻게 되나 |
|---|---|
| 아무것도 안 고르고 카드를 누름 | 화면 안내가 "하나 이상 골라주세요"로 흔들리고, 진행하지 않음 |
| 연결 중 오류 | 화면 아래에 오류 문구가 뜨고, 다시 고를 수 있는 상태로 돌아옴 |
| 연결하기 싫음 | 오른쪽 위 **"연결 없이 둘러보기"** → 기본 취향으로 코스 추천 |

화면 아래 **"기록은 이렇게만 써요"**를 누르면 개인정보 안내가 펼쳐집니다.

두 가지를 연결할 수 있고, 하나만 연결해도 됩니다.

| 연결 항목 | 읽는 것 |
|---|---|
| **유튜브 알고리즘** | 좋아요한 영상, 구독 채널, 영상 카테고리, 관심 주제 |
| **사진첩** | 찍은 시간, 장소 종류, 재방문, 동행 수 |

### 사진을 고를 때

- 기기 안에서 **512px로 줄여서** 보냅니다. 원본은 나가지 않습니다.
- 최대 12장만 씁니다. 더 고르면 앞뒤로 치우치지 않게 고르게 솎습니다.
- **브라우저가 열 수 없는 형식(아이폰 HEIC 등)은 고르는 순간 걸러냅니다.**
  → "3장은 이 브라우저가 열 수 없는 형식이라 제외했어요 (아이폰 HEIC는 JPG로 저장해 주세요)"

> **개인정보 고지**: 줄인 사진은 취향 분석에 한 번만 쓰이고 저장되지 않습니다. 다만 **분석을 위해 외부 AI API로 전송됩니다.** 현재 화면 안내문에는 "외부 AI로 전송된다"는 문장이 빠져 있어 추가가 필요합니다 (아래 [아직 안 된 것](#아직-안-된-것) 참고).

### 유튜브를 연결할 때

구글 로그인 화면으로 이동합니다. 읽기 전용 권한으로 좋아요·구독 목록만 봅니다.

로그인하러 떠날 때 **이미 고른 사진은 기기 안에 잠깐 보관했다가** 돌아오면 복원합니다. 사진을 다시 고르게 만들지 않습니다.

토큰은 저장하지 않습니다. 수집이 끝나면 바로 버립니다.

## ③ 분석 — 키오스크 화면의 "분석 중… → 분석 완료!"

카드가 꽂힌 채로 카메라가 키오스크 화면 가까이 다가가고, 앞쪽에 흐린 화분이 들어와 깊이감을 줍니다.

### 진행 순서

1. **분석 중…** — "당신의 취향을 하나씩 꺼내고 있어요" 아래에 원숭이 얼굴을 감싼 **원형 게이지**가 있고, 유튜브·사진·하트·음표 아이콘이 주변에 떠 있습니다.
2. 게이지는 **항상 0%에서 시작해 끊기지 않고 채워집니다.**

   | 구간 | 게이지 |
   |---|---|
   | 유튜브 로그인에서 돌아와 기록을 받는 중 | 0% |
   | 기록을 하나씩 읽는 중 (0.28초에 하나) | 0% → 80% |
   | 기록은 다 읽고 AI 분석 결과를 기다리는 중 | 80% → 95%, 아주 천천히 (멈춘 것처럼 보이지 않게) |
   | AI 분석 완료 | 100%까지 채운 모습을 0.8초 보여줌 |

   분석이 아무리 빨리 끝나도 "분석 중" 화면은 최소 1.3초 보여줍니다.
3. **분석 완료! ✦** — "당신의 취향이 분석되었어요." 아래로 원숭이가 빼꼼 올라오고, 결과 카드에 **취향 태그(최대 5개)**와 **고른 사진(최대 4장)**이 보입니다.
4. **"결과 보기"**를 눌러야 ④ 취향 확인·수정으로 넘어갑니다. 자동으로 넘어가지 않아 결과를 볼 시간이 있습니다.

분석 도중 왼쪽 위 **"분석 취소"**를 누르면 ② 기록 연결로 돌아갑니다. 늦게 도착한 이전 분석 결과는 화면을 넘기지 못하게 막혀 있습니다.

> 휴대폰에서 "동작 줄이기"를 켠 사용자에게는 카메라 이동·카드 꽂기 같은 움직임을 끄고 바로 보여줍니다.

### 뒤에서 일어나는 일

**1단계 — 사진 읽기**
AI가 사진마다 장소 종류(식당·카페·공원·전시장…), 어울리는 태그, 함께 있는 사람 수를 읽습니다. EXIF에서 뽑은 촬영 시각과 동네도 함께 씁니다.

**2단계 — 가중 합산**
사진과 유튜브를 각각 "항목별 비율"로 바꾼 뒤 **사진 0.6 : 유튜브 0.4**로 더합니다.

핵심은 **근거가 적은 쪽은 가중치를 깎는다**는 것입니다.

| 상황 | 결과 |
|---|---|
| 사진 2장 + 유튜브 200개 | 유튜브가 3배 강하게 반영 |
| 사진 10장 + 유튜브 200개 | 사진이 1.5배 강하게 반영 |
| 사진 10장 + 유튜브 5개 | 사진이 6배 강하게 반영 |

사진 몇 장이 유튜브 수백 개를 무조건 이기지 않습니다. 실제로 사진 3장에서 카페가 앞서도, 유튜브 200개가 식사를 가리키면 최종 결과가 뒤집힙니다.

**3단계 — 설명과 질문 만들기**
계산된 값은 AI가 바꾸지 못합니다. AI는 그 값을 설명하는 문장과, 이 사람에게만 맞는 질문 주제를 만듭니다.

### 분석이 잘 안 될 때

| 상황 | 어떻게 되나 |
|---|---|
| 사진 읽기 실패 | 사진만 버리고 **유튜브만으로 계속 진행**. 화면에 "사진을 읽지 못해 유튜브 기록만으로 분석했어요" 표시 |
| 유튜브 미연결 | 사진만으로 분석 (가중치 사진 100%) |
| 분석 전체 실패 | 유튜브 키워드 규칙으로 대략 맞추고, **실패했다고 화면에 알림** |
| 양쪽 다 근거 없음 | "분석할 기록이 없어요" |

> 실패했을 때 그럴듯한 가짜를 보여주지 않습니다. 가본 적 없는 곳을 "단골"이라고 말하는 것보다, 못 읽었다고 말하는 게 낫습니다.

## ④ 취향 확인·수정

> **"이런 취향이 보여요"**
> 다르면 눌러서 바꿔주세요. 바꾼 값으로 다시 추천해요.

읽어낸 취향을 보여주고, **틀리면 사용자가 직접 고칠 수 있게** 합니다. AI가 정한 걸 그대로 강요하지 않습니다.

### 항상 나오는 주제 6개

| 주제 | 선택지 |
|---|---|
| 분위기 | 활기찬 / 편안한 / 조용한 |
| 시간대 | 막대를 끌어 시작·종료 시각 직접 지정 |
| 활동성 | 적음 / 중간 / 많음 / 매우 많음 |
| 일정 | 촘촘하게 여러 곳 / 여유롭게 한 곳에 오래 |
| 누구랑 | 혼자 / 연인 / 친구 / 가족 / 동료 |
| 예산 | 슬라이더로 1인 기준 금액 |

### 매번 달라지는 주제 4개

여기가 이 서비스의 특징입니다. **일반적인 설문 문항이 아니라, 이 사람 기록을 본 사람만 쓸 수 있는 질문**을 AI가 매번 새로 만듭니다.

예시 — 저녁 시간 망원 사진이 많은 사용자:

> **요즘 반복되는 저녁**
> ㆍ 노포에서 조용히 한잔
> ㆍ 강변 걷다가 늦은 저녁
> ㆍ 혼자 앉을 자리 있는 술집

예시 — 아침 산책 사진이 많은 사용자:

> **아침에 걷는 길**
> ㆍ 한적한 강변 길을 천천히 산책
> ㆍ 조용한 카페에서 여유로운 브런치
> ㆍ 아침 볕 드는 전망 자리

주제마다 **왜 이걸 묻는지 근거**가 함께 표시됩니다.
→ "사진 4장 모두 촬영 시간이 오전 7시로 집계됨"

### 근거를 숫자로 보여준다

각 주제 옆에 계산 근거가 그대로 노출됩니다.

> 조용한 100% (사진 4장 100%, 가중치 사진 0.3 / 유튜브 0.0)

"AI가 그렇게 판단했습니다"로 끝내지 않고, **어떤 데이터에서 어떤 비중으로 나온 값인지** 보여줍니다.

## ⑤ AI 코스 추천

확정한 취향과 조건으로 마포구 실제 장소를 엮은 코스를 만듭니다.

### 지켜지는 것

**장소를 지어내지 않습니다.** 실제 수집한 마포구 장소 목록 안에서만 고릅니다.

**시간을 채우되, 현실적으로 채웁니다.**

| 장소 종류 | 머무는 시간 |
|---|---|
| 식사 | 40~100분 |
| 카페 | 30~120분 |
| 한잔 | 50~150분 |
| 체험 | 45~150분 |
| 문화(전시) | 30~120분 |
| 산책 | 20~90분 |

시간이 남으면 **한 곳에 더 오래 머물게 하는 게 아니라 장소를 더 넣습니다.** "15시에 식당, 다음 일정이 18시" 같은 코스가 나오지 않습니다.

**밥 먹고 바로 또 밥을 먹지 않습니다.** 식사·카페·한잔은 연달아 배치되지 않습니다.

**근거 없는 말을 쓰지 않습니다.** "인기", "유명", "맛집", "한적한", "웨이팅 없는" 같은 확인 불가능한 표현은 제목·설명 어디에도 넣지 않습니다.

### 실제 결과 예시

```
여유롭게 · 15~21시 · 망원 · 연인

[노을과 파스타 데이트]
  15:00   식사   페리도트 망원        100분
   ↓ 도보 6분
  16:46   카페   광합성카페          105분
   ↓ 도보 7분
  18:32   한잔   아루감             148분
  → 21:00 종료
```

```
촘촘하게 · 15~21시 · 망원 · 연인

[망원 밤노을 식사 데이트]
  15:00   산책   망원시장            55분
  15:59   식사   타코닷 망원시장본점   100분
  17:43   체험   우리들의 아지트       45분
  18:35   한잔   망원도             145분
  → 21:00 종료
```

### 코스 카드에 보이는 것

- 취향 일치도 (%)
- 총 소요 시간과 시작~종료 시각
- 1인 / 총 예산
- 지도 미리보기 (실제 도보 경로선)
- 예약 가능한 곳 표시 (캐치테이블 / 네이버 예약)

조건(지역·시간·인원·예산)은 결과 화면에서 언제든 바꿀 수 있고, 바꾸면 다시 추천받습니다.

## ⑥ 코스 시작

코스를 골라 **"코스 시작"**을 누르면 전체 화면 지도로 전환됩니다.

보이는 것:
- 실제 네이버 지도 위에 코스 장소 핀 (번호 · 도착 예정 시각 · 이름)
- **내 현재 위치** (파란 점, 실시간 갱신)
- 다음 목적지까지의 **실제 도보 경로** (파란 굵은 선)
- 아직 안 간 구간은 초록 점선
- 하단에 이동 순서와 다음 목적지 카드

## ⑦ 길안내

지도 위쪽에 내비게이션 안내가 뜹니다.

```
┌──────────────────────────────┐
│  ↰   20m 앞                  │
│      미자카야에서 좌회전 후 203m 이동 │
└──────────────────────────────┘
```

하단에는 남은 거리와 시간이 표시됩니다.

> **도보 경로 1.4km · 약 19분**

직선 거리가 아니라 **실제 걸어야 하는 경로 기준**입니다.

### 걷는 동안

- **경로에서 50m 이상 벗어나면 자동으로 다시 찾습니다.**

## 시나리오로 보기

### 시나리오 A — 사진첩만 연결한 사용자

1. 로그인 없이 둘러보기
2. 사진첩만 연결 · 최근 사진 8장 선택 (유튜브는 끔)
3. 분석 → 사진 가중치 0.48 / 유튜브 0.0
4. "조용한 · 낮 · 활동성 적음"으로 읽힘, 근거는 "사진 8장 중 6장이 공원·강변"
5. 동적 주제 "아침에 걷는 길"에서 **"한적한 강변 길을 천천히 산책"** 선택
6. 망원 · 3시간 · 2명 조건으로 코스 4개 추천
7. 마음에 드는 코스 저장 후 코스 시작 → 첫 목적지까지 길안내

### 시나리오 B — 유튜브만 연결한 사용자

1. 이메일 로그인
2. 유튜브만 연결 → 구글 로그인 → 좋아요 180개 · 구독 42개 수집
3. 분석 → 유튜브 가중치 0.4 / 사진 0.0
4. "미식 · 활기찬" 성향으로 읽힘, 시간대·분위기는 사진이 없어 기본값
5. 시간대를 직접 **18~22시**로 조정
6. 홍대 · 4명 · 3.5만원 이하로 코스 추천

### 시나리오 C — 둘 다 연결했는데 사진이 HEIC인 사용자

1. 사진 12장 선택 → **"12장은 이 브라우저가 열 수 없는 형식이라 제외했어요"**
2. 사진첩 연결이 자동으로 해제되고, 유튜브만 남음
3. 사진을 JPG로 다시 저장해 재시도하거나, 유튜브만으로 진행
4. 유튜브만으로 진행해도 **분석은 정상 완료됨** (한쪽이 막혀도 다른 쪽은 진행)
